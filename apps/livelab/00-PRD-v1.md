# FlowLens LiveLab PRD v1

## 1. 产品定义

FlowLens LiveLab 是一个用于求职作品集和面试讲解的、本地可运行的视频内容分发实验诊断原型。它连接 FlowLens 已完成的离线策略分析，但不把离线结果包装成线上实验结果。

一句话价值：让策略产品经理在做指标解读之前，先证明“实验分得对、流量进得来、事件记得全”。

## 2. 目标用户与任务

主要用户：推荐/内容分发策略产品经理、数据分析师、算法协作方。

核心任务：

1. 快速判断一个实验是否具备可解释性。
2. 把控制组和实验组的策略差异、流量比例、主指标与护栏指标放在同一上下文中。
3. 在看 uplift 前完成 SRM、触发率、污染、事件完整性检查。
4. 记录“继续、暂停、迭代”的决策理由，避免只报一个 p-value。

## 3. MVP 范围

### 包含

- 三个预置模拟实验及实验队列。
- FlowLens RankLab Gate C 的一张可追溯 E3 离线回放结果卡。
- A/B 分流配置与事件漏斗。
- 固定种子、本地运行的事件模拟器。
- SRM、触发率、跨组污染、事件完整性、版本一致性五类诊断。
- 主指标与护栏指标对照。
- 决策卡草稿与浏览器本地保存。
- 桌面、平板和窄屏响应式布局。

### 不包含

- 真实用户流量、腾讯视频数据或线上实验结果。
- 服务端持久化、登录权限、多人协作。
- 宣称因果显著性或业务增量。
- 自动发布、真实实验启停或生产告警。

## 4. 事件合同

事件链：

`eligible → assigned → exposed → clicked → content_start → long_view / negative_feedback`

每条事件至少包含：

- `event_id`
- `simulated_user_id`
- `experiment_id`
- `variant`
- `event_name`
- `occurred_at`
- `strategy_version`

诊断含义：

- eligible：进入实验候选人群。
- assigned：完成稳定分流。
- exposed：实际看到策略结果；触发率以 exposed / assigned 计算。
- clicked：发生内容点击。
- content_start：进入有效播放。
- long_view：达到模拟长播阈值。
- negative_feedback：出现“不感兴趣/减少推荐”等负反馈。

## 5. 模拟与统计口径

- 使用固定种子生成批次，保证首屏可复现。
- SRM 使用两组分流的 Pearson 卡方统计量；两组时以 `erfc(sqrt(χ²/2))` 计算近似 p-value。
- 原型把 `p < 0.01` 标为分流异常风险，不把 `p >= 0.01` 表述为“证明随机化完全正确”。
- 触发率、污染率、事件完整性和版本一致性使用显式阈值；阈值仅是演示规则，不代表腾讯视频内部标准。
- uplift 为模拟样本中的描述性差异；页面始终展示“模拟流量”标记。

### Gate C 离线回放扩展

- 页面顶部结果卡从 `data/ranklab_offline_run.js` 静态读取，不参与浏览器模拟器计算。
- 结果来自 KuaiRand-Pure 公开数据上同一验证人群、候选集、标签和时间切分的 E3 离线回放。
- 指标展示真实运行所得的点估计与配对用户 bootstrap 区间；它们不是在线因果效应。
- 只有验证门槛通过后才能读取冻结测试集。本轮验证决策为 `ITERATE_AND_RETEST`，因此没有运行冻结测试集。

## 6. 信息架构

- 左侧：实验队列与整体范围。
- 中央：当前实验上下文、主导航、策略配置与分析工作区。
- 右侧：实验健康检查器，保持当前异常可见。
- 窄屏：三栏依次堆叠，核心操作仍可直接触达。

## 7. 关键交互

- 切换实验：保留主导航位置，替换实验上下文。
- 模拟下一批事件：新增一批本地事件并重新计算所有诊断与指标。
- 暂停/恢复：只改变原型状态和事件记录，不触发外部系统。
- 导航切换：策略对照、健康检查、指标分析、决策卡均在同一工作区切换。
- 决策保存：写入 `localStorage`；提供“恢复模板”回滚。

## 8. 视觉方向

选择方向 B：GrowthBook 风格的策略实验台。

- 模式：亮色、冷白背景、深石墨文字。
- 主色：低饱和青绿；表示可执行与“健康”，但不会铺满界面。
- 风险色：琥珀与红，仅用于需关注或失败状态。
- 密度：紧凑但可扫描，14–16px 正文字号，8px 网格。
- 边缘：6–10px 圆角、1px 冷灰边框、极少阴影。
- 动效：仅反馈、引导和连续性；150–220ms，支持 reduced motion。

## 9. 验收标准

- 无 Docker/Java/npm 依赖即可启动。
- 三个实验均可切换，且健康检查随选择变化。
- “模拟下一批事件”会改变事件量并重新计算指标。
- 主导航五个入口可键盘访问，当前项有 `aria-current`。
- 所有按钮具备 hover、focus、active、disabled 或 busy 状态。
- 页面在 1440px、1024px、390px 宽度下无横向内容溢出。
- 所有强结果都带有“模拟”或“演示阈值”说明。
- Gate C 结果卡显示数据集、切分、样本量、运行 ID、证据等级与决策，不与模拟指标混用。
